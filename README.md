# Rose's Cove Tiki Lounge — v3.8

1080 × 1920 GitHub Pages-ready website. Upload the contents of this ZIP to your repository root, preserving folders.

## Screen 3 rebuild
- Replaced the v3.7 flat-vector-derived graphics with individual **transparent raster artwork** taken from the earlier richly textured carved-wood character concept: hollow-socket base, independent eyeballs, heavy wooden brows, independent sliding lids, and carved lower jaw. The real baked-in wood texture, wear, paint and dimensional highlights move with each part.
- Retained JavaScript-driven facial expressions, blinking, eye glances, jaw movement and trivia-reactive talking. Select expressions under Settings > Screen 3.
- Uses a **character-free** volcanic background; removed the old overlapping tiki and the large duplicate sign lettering from the scene. Lava-rock trivia plaque and all facts remain.
- Screens 1 and 2, saved settings, and fullscreen cursor behavior are retained from v3.7.
